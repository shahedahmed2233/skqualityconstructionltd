The website should have a **high-end UK construction company aesthetic**, similar to a premium local contractor website.

### Visual style

* Mid-dark + warm white combination
* White / off-white content sections
* Deep charcoal or dark navy accents
* Subtle bronze/gold accent color
* Large premium typography
* Strong spacing and clean layouts
* High-quality construction/roofing visual feel
* Subtle borders
* Soft shadows
* Rounded corners, but NOT excessive
* Elegant hover effects
* Premium buttons
* Lots of breathing room
* Strong visual hierarchy

Avoid making the entire website black/dark.

The overall feeling should be:

**Premium + Reliable + Established + Professional + British + Craftsmanship**

Avoid:

* Generic SaaS design
* Overly colorful gradients
* Excessive glassmorphism
* Cartoonish icons
* Huge unnecessary animations
* AI-looking layouts
* Excessive rounded cards
* Overly dark website
* Stock-template appearance
